# Inseto Cards v2.0.2 — Motion Overhaul

Patch visual/UX para a versão de batalha.

## Arquivos
- `index.html` — carrega GSAP e o novo sistema de motion.
- `js/game.js` — versão atualizada do motor.
- `js/multiplayer.js` — multiplayer/revanche/turno mobile.
- `js/battle-fx.js` — camada GSAP: FLIP, cinematics, tilt 3D, partículas, ripples, mobile touch.
- `css/style.css` — UI responsiva + efeitos visuais.

## Biblioteca externa
GSAP 3.13.0 via CDNJS. Se estiver offline, o jogo continua funcionando com o CSS/FX nativo já existente; apenas os efeitos GSAP não serão ativados.
