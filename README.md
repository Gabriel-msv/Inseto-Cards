# Inseto Cards v2.0.7 — efeitos visuais

Correção visual focada nas cartas de efeito e nos indicadores de efeitos aplicados às cartas.

## Alterações
- Removido o brilho excessivo/estourado das cartas afetadas.
- O indicador de Lupa/Teia/Aranha/Centopeia agora usa um contorno discreto, sem aplicar `brightness()` na arte.
- Evitado conflito visual entre o brilho dos efeitos e as animações 3D/pendulares das cartas.
- Cartas de efeito agora têm identidade visual própria, sem mostrar `ATK 0 / HP 0`.
- Cartas de efeito exibem `EFEITO` ou `EQUIPÁVEL` no rodapé.
- Mantida a estrutura e responsividade atuais.
- Casca, Casulo Real e Fumaça continuam removidas da versão atual.

## Arquivos alterados
- `game.js`
- `style.css`

Substitua somente esses dois arquivos na versão atual do projeto.
